## 🆘 TROUBLESHOOTING

### ❌ Error: "Could not find table users"
```
→ Go back to TASK 1
→ Did you run BOTH SQL queries?
→ Check Supabase Table Editor
→ Do you see "users" table listed?
→ If not, run SQL again
```

### ❌ Error: "Cannot find module"
```
→ Stop server (Ctrl+C)
→ Type: npm run install:all
→ Wait for completion
→ Type: npm run dev
```

### ❌ App won't load at http://localhost:5173
```
→ Is Vite running? Check terminal
→ Is port 5173 free?
→ Try: http://localhost:5173 (refresh)
→ Hard refresh: Ctrl+Shift+R
```

### ❌ Login button not working
```
→ Hard refresh: Ctrl+Shift+R
→ Check browser console (F12)
→ Is backend running? Check terminal
→ Try again
```
